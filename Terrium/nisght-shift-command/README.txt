NIGHT SHIFT COMMAND V3

Installation :
1. Dézipper le dossier.
2. Ouvrir index.html dans un navigateur.
3. Sur téléphone, envoyer le dossier ou héberger les fichiers.
4. La sauvegarde se fait automatiquement dans le navigateur.

Fichiers :
- index.html : structure du jeu
- style.css : interface responsive cyberpunk
- data.js : contenu du jeu, lore, bâtiments, unités, missions, sites, technologies
- game.js : logique du jeu, sauvegarde, combats, production, événements

Conseil dev :
Pour ajouter du contenu, modifie surtout data.js.
